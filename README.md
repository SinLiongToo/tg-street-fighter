# 台語快打旋風 700 (TAIGI FIGHTER 700) 🥊⚡

> **90年代卡普空（Capcom）復古快打旋風風格 × 教育部臺灣台語推薦用字 700 詞街機格鬥學習遊戲！**
> 
> 融合經典格鬥遊戲美學（雙人血條、延遲扣血殘影、99秒倒數、KO、波動拳、昇龍拳、旋風腿、超必殺技）與《番薯仔大冒險》的在地文化闖關趣味，將「台語 700 單字卡」轉化為超熱血的街機格鬥！

## 🎮 遊戲特色

1. **經典街機 16-bit 復古快打風格**
   - **血條與 HUD**：P1 阿龍（台語拳豪） vs P2 各路擂台霸王、雙圓勝場燈號（● ○）、延遲紅色扣血殘影、99 秒倒數、Combo 連擊計數器。
   - **EX 氣條（Super Meter）**：累積連擊可集滿氣條，爆發全螢幕震撼「真空波動拳」超必殺技！
   - **四大多層視差台灣風情擂台**：
     - **第 1 關：夜市擂台・大東夜市**（霓虹燈招牌、隨風搖曳紅燈籠、熱鬧歡呼人群、地面反光雨水水窪）
     - **第 2 關：廟口廣場・鎮瀾宮前**（燕尾脊宮廟、剪黏飛龍、青石獅、裊裊香爐煙）
     - **第 3 關：港都碼頭・旗津夕陽**（落日彩霞、遠方吊臂、起伏漁船與三角彩旗）
     - **第 4 關：大稻埕天台・終極決戰**（巴洛克紅磚雕飾、巨大圓月、暗夜雷電）
   - **格鬥動畫動作**：呼吸跳躍（Idle）、刺拳（Light Jab）、重拳（Heavy Straight）、旋風踢（Roundhouse Kick）、氣功波（波動拳 Hadouken）、升龍拳（Shoryuken）、被擊退受創、暈眩旋轉金星、KO倒地！
   - **90 年代街機像素風角色**：角色用關節骨架（肩、肘、髖、膝）繪製，粗黑描邊加兩階明暗；每個擂主都有自己的服裝與造型。
   - **逐格動畫**：像老街機的手繪動畫一樣，每個動作停幾格再跳到下一格（蓄力 → 出招 → 收招），不是平滑補間。
   - **像素畫面**：場景以半解析度繪製再放大，呈現顆粒像素感；文字與字幕維持清晰。可在上方「👾 像素」按鈕開關。
   - **街機打擊手感**：
     - 出拳、踢腿會先蓄力，再衝刺到對手面前命中，然後跳回原位；衝刺帶殘影。
     - 命中時爆出尖角星形火花，被打的一方閃白光。
     - 命中瞬間畫面停格（Hit-stop）並震動，被打的一方會往後退。
     - 昇龍拳真正騰空飛起；KO 時角色被打飛、旋轉倒地彈起，下一回合再站起來。
     - 勝利時跳起、高舉拳頭。
     - 招式結束平滑回到站姿；ROUND / FIGHT / K.O. 字幕彈入，傷害數字放大彈出。
   - **各種螢幕同速**：固定 60Hz 更新，在 60 / 120 / 144Hz 螢幕上動畫速度都一樣；系統開啟「減少動態效果」時會減輕畫面震動並關閉殘影。
   - **CRT 復古掃描線濾鏡**：可隨時於頂部開關，重現老式映像管大型機台質感。

2. **教育部臺灣台語推薦用字 700 詞完整收錄**
   - 完整 700 常用字詞，包含：
     - 漢字本字（如「阿妗」、「隘勇」、「鬱卒」等）
     - 正統教育部臺灣閩南語羅馬字拼音（Tâi-lô / 臺羅）
     - 華語對應釋義
     - 常用語境例句
     - **教育部真人發音即時串流**（kiantiong / 教育部字辭典原聲真人發音，支援重播與離線語音容錯）

3. **四大格鬥招式題型對決**
   - 👊 **輕拳出招（Light Punch）**：依臺羅拼音辨別漢字。
   - 💥 **重拳連擊（Heavy Punch）**：依漢字選擇正確臺羅聲調拼音。
   - 🔥 **波動拳衝擊（Hadouken）**：依華語釋義與例句發射對譯衝擊波。
   - ⚡ **昇龍拳（Shoryuken）**：純聽真人原音辨字對決！
   - ⚡ **超必殺技（SUPER COMBO）**：集滿 EX 氣條時按下 Space / EX 鍵，瞬間造成毀滅性爆擊！

4. **四大遊戲模式**
   - 🥊 **街機闖關模式（Arcade Story）**：連續挑戰 4 位擂台魔王，採三戰兩勝制，爭奪全台總冠軍！
   - 🏯 **街頭修練館（Dojo Training）**：全 700 詞自由查詢、聽音、複習，還可以對著木人樁試招練習！
   - 🔥 **無盡生存戰（Survival Mode）**：一條血量連續挑戰無盡對手，考驗台語字詞反應極限並紀錄最高分！
   - 🆚 **雙人搶答對戰（2P Versus）**：兩人同一台電腦或平板對戰。1P 是阿龍，2P 從四位擂主（火雞哥、鐵拳廟公伯、港都海霸王、考官修羅）選一位，場景跟著角色換。
     - 同一題兩人搶答，先按的算數。
     - **答對**出招打對手：傷害 22；2.8 秒內「秒答」傷害 30。
     - **答錯**換對手反擊，自己扣 18，亂猜會吃虧！
     - 三戰兩勝；時間到血多者勝，同血平手。比完可直接「再戰一場」。
     - 雙人模式不使用 SUPER 氣條，以維持公平。

5. **全平台操作支援（PC 鍵盤 + 手機觸控雙用）**
   - **PC 鍵盤**：
     - `1`, `2`, `3`, `4` 或 `J`, `K`, `U`, `I` 或 `A`, `B`, `C`, `D`：快速選招出拳！
     - `Space` 或 `S`：爆發超必殺技（SUPER COMBO）
     - `R`：重播真人發音
     - `Enter`：開始投幣開戰
     - `ESC`：隨時回主選單
   - **手機觸控**：
     - 底部虛擬八向搖桿 + A/B/C/D 四色街機大微動按鈕 + EX 大招鈕。
   - **雙人對戰操作**：
     | 玩家 | 鍵盤 | 觸控 |
     |---|---|---|
     | 1P 阿龍 | `1` `2` `3` `4`（上排數字鍵） | 題目下方左邊藍框的 A B C D |
     | 2P 擂主 | `7` `8` `9` `0`（上排數字鍵）或數字鍵盤 `1`-`4` | 題目下方右邊橘框的 A B C D |

     `R` 重播發音、`ESC` 回主選單。觸控按鈕是手指一碰就算數，兩人同時按也是手快的贏。
